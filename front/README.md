### Documentation ###

### Quick Start ###
* Install node.js: https://nodejs.org​
* Install yarn package manager: https://yarnpkg.com/​
* Install node modules by running terminal command `yarn install`
* Run the app `yarn start`
* Or build production app `yarn build`
